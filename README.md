# Simbi Catalog

Gostaria de criar um catalogo digital para que não seria focado inteiramente em delivery, nav erdade mais focado em produtos que não são produtos congelados e afins sabe? Nesse MVP precisamos ter link externo para o cliente acessar o cardapio, e afins, algo realmente bem bonito e não pode ter cara de IA de maneira nenhuma, cadastro de produtos e afins, selecionar qual vai para o catalogo e qual não vai, coisas nesse sentido. O cardapio se chama simbi, preciso de um MVP autamente funcional, conectado ao banco de dados e sem login por google a principio.
